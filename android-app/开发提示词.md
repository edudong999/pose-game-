## 二、功能模块与界面

### 2.1 用户模块

#### 登录界面 (LoginActivity)
- 输入框：昵称、密码
- 按钮：登录、注册入口
- 验证：非空检查
- 记住登录状态（SharedPreferences 存储 token）

#### 注册界面 (RegisterActivity)
- 输入框：昵称、密码、确认密码
- 按钮：注册、返回登录
- 验证：密码一致性、昵称长度

**接口对接**：
```
POST /api/user/register
POST /api/user/login
GET /api/user/info
Header: Authorization: Bearer <token>
```

---

### 2.2 主界面 (MainActivity)

#### 底部导航栏（3个 Tab）
1. **关卡** - 展示所有可挑战关卡
2. **记录** - 闯关历史和排行榜
3. **我的** - 个人中心和贴纸墙

#### 关卡列表界面 (LevelListFragment)
- 网格布局展示关卡卡片
- 每个卡片显示：
  - 关卡名称（如"比心挑战"）
  - 关卡图标/贴纸
  - 状态标签（已解锁/未解锁/已通过）
- 点击进入关卡详情

**接口对接**：
```
GET /api/levels
```

---

### 2.3 关卡详情界面 (LevelDetailActivity)

#### 页面内容
- 标准动作示意图（网络图片 or 本地资源）
- 动作名称和描述
- 通过分数要求
- 奖励贴纸预览
- **开始挑战** 按钮（大按钮，醒目）

#### 动作提示
- 显示标准姿态的关键点示意
- 可以有动画演示动作

**接口对接**：
```
GET /api/levels/{id}
GET /api/levels/pose/types
```

---

### 2.4 相机拍摄界面 (CameraActivity)

#### 功能要求
- 实时摄像头预览（CameraX）
- 相机切换（前/后摄像头）
- 倒计时显示（3-2-1）
- 拍照按钮
- 录像按钮（可选，≤5秒）
- 取消按钮

#### 流程
1. 用户点击"开始挑战"
2. 进入相机界面，倒计时3秒
3. 用户做动作，拍照/录像
4. 提交到后端识别

**接口对接**：
```
POST /api/pose/recognize
POST /api/pose/recognize/video
```

---

### 2.5 结果展示界面 (ResultActivity)

#### 成功页面
- 大字显示"闯关成功！"
- 得分展示（0-100分）
- 各部位得分详情（头、肩、手、身体）
- 获得贴纸动画/展示
- **再玩一次** / **返回关卡** 按钮

#### 失败页面
- 显示"差一点哦"
- 得分
- 与标准动作对比提示
- **重新挑战** / **返回关卡** 按钮

**接口对接**：
```
POST /api/game/record
```

---

### 2.6 闯关记录界面 (RecordFragment)

- 列表展示闯关历史
- 每条记录显示：
  - 关卡名称
  - 得分
  - 是否通过
  - 时间

**接口对接**：
```
GET /api/game/records
```

---

### 2.7 排行榜界面 (LeaderboardActivity)

- 选择关卡
- 显示前10名玩家
- 排名、昵称、得分、头像

**接口对接**：
```
GET /api/game/leaderboard/{level_id}
```

---

### 2.8 个人中心界面 (ProfileFragment)

- 用户信息（昵称、头像、总分、解锁关卡数）
- 贴纸墙入口
- 退出登录

**接口对接**：
```
GET /api/user/info
GET /api/stickers
```

---

### 2.9 贴纸墙界面 (StickerWallActivity)

- 网格展示所有贴纸
- 已解锁贴纸（彩色）
- 未解锁贴纸（灰色/锁定状态）
- 点击查看贴纸详情

**接口对接**：
```
GET /api/stickers/all
GET /api/stickers
```

## 六、开发注意事项

### 1. 网络权限
```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
```

### 2. 登录状态管理
- 登录成功后保存 token 到 SharedPreferences
- 请求时从 SharedPreferences 读取 token 放入 Header
- token 过期或无效时跳转登录页面

### 3. 错误处理
- 网络异常：显示 Toast "网络连接失败"
- 服务器错误：显示 Toast 后端返回的 msg
- 401 未授权：跳转登录页面

### 4. 加载状态
- 每个网络请求显示 Loading 对话框
- 超时时间设置为 30 秒

### 5. 相机权限
```xml
<uses-feature android:name="android.hardware.camera" android:required="false" />
```

## 八、Retrofit 接口定义

```java
public interface ApiService {

    // 用户模块
    @POST("api/user/register")
    Call<ApiResponse<UserInfo>> register(@Body Map<String, String> params);

    @POST("api/user/login")
    Call<ApiResponse<UserInfo>> login(@Body Map<String, String> params);

    @GET("api/user/info")
    Call<ApiResponse<UserInfo>> getUserInfo(@Header("Authorization") String token);

    // 关卡模块
    @GET("api/levels")
    Call<ApiResponse<LevelListResponse>> getLevels();

    @GET("api/levels/{id}")
    Call<ApiResponse<Level>> getLevelDetail(@Path("id") int levelId);

    @GET("api/levels/pose/types")
    Call<ApiResponse<PoseTypeResponse>> getPoseTypes();

    // 姿态识别
    @Multipart
    @POST("api/pose/recognize")
    Call<ApiResponse<PoseResult>> recognizePose(
        @Part MultipartBody.Part image,
        @Query("level_id") int levelId
    );

    // 游戏记录
    @POST("api/game/record")
    Call<ApiResponse<GameRecordResponse>> submitRecord(
        @Header("Authorization") String token,
        @Body Map<String, Object> params
    );

    @GET("api/game/records")
    Call<ApiResponse<RecordListResponse>> getRecords(
        @Header("Authorization") String token,
        @Query("page") int page,
        @Query("pageSize") int pageSize
    );

    @GET("api/game/leaderboard/{levelId}")
    Call<ApiResponse<LeaderboardResponse>> getLeaderboard(@Path("levelId") int levelId);

    // 贴纸
    @GET("api/stickers")
    Call<ApiResponse<StickerListResponse>> getMyStickers(@Header("Authorization") String token);

    @GET("api/stickers/all")
    Call<ApiResponse<StickerListResponse>> getAllStickers();
}
```
